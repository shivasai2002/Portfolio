## 4. DSA & Coding Plan

### Why DSA Matters for Your Goals

Google, Meta, JPMorgan — all require LeetCode-style coding rounds regardless of role. Even AI Engineer roles at top companies require passing a coding screen first.

### Realistic Plan for Full-Time Workers

**Daily commitment:** 30–45 minutes, 5 days/week
**Tool:** NeetCode.io (free, structured, video solutions)
**Target:** NeetCode 150 in 6 months

### Monthly Breakdown

| Month | Topics | Target Problems |
|---|---|---|
| 1 | Arrays, Strings, Hashing | 20 |
| 2 | Two Pointers, Sliding Window, Stack | 20 |
| 3 | Binary Search, Linked Lists | 20 |
| 4 | Trees, Tries | 20 |
| 5 | Graphs, Heap/Priority Queue | 20 |
| 6 | Dynamic Programming, Greedy, Intervals | 20 |

**Total: 120 problems in 6 months** (solid foundation for FAANG screens)

### Strategy

- Solve Easy first, then Medium — skip Hard until month 5+
- Time yourself: Easy = 15 min, Medium = 30 min
- If stuck after 20 min — read the approach, code it yourself
- Review wrong answers in a notebook/Notion
- Language: Python (your strongest, matches AI interviews)

### AI-Specific Coding Topics

Beyond LeetCode — these come up in AI engineer interviews:
- Implement a simple tokenizer
- Build a vector similarity search from scratch
- Write a basic attention mechanism
- Implement beam search
- Build a simple RAG pipeline from scratch (no frameworks)

### Repo Structure Standard (apply to every project)

```
project-name/
├── README.md          (architecture diagram, demo GIF, setup instructions)
├── docs/              (architecture decisions, design docs)
├── src/               (main source code)
├── tests/             (unit + integration tests)
├── notebooks/         (experimentation, analysis)
├── .env.example       (never commit .env)
├── requirements.txt   (or pyproject.toml)
└── Dockerfile         (containerize when possible)
```

### README Standard for Each Project

Every project README must have:
- What it does (2–3 sentences)
- Architecture diagram (use draw.io or Mermaid)
- Tech stack badges
- Setup instructions
- Demo (screenshot or GIF)
- What you learned
- Future improvements

### Commit Habits

- Meaningful commit messages: `feat: add hybrid search to RAG pipeline`
- Use conventional commits: `feat`, `fix`, `docs`, `refactor`, `test`
- Commit small and often — daily progress beats weekly dumps
